经纬咨询决策工作台 v0.1.0
============================

1. 双击 Jingwei.exe。
2. 经纬会打开默认浏览器；第一次使用请点“新建题目”。
3. 保留“经纬正在本机运行”的提示窗；提示窗中的“取消”会安全退出应用。

提示窗按钮
----------

- “是”：重新打开工作台。
- “否”：打开数据与导出目录。
- “取消”：安全退出经纬。

你的数据在哪里
----------------

点击控制窗口中的“打开数据与导出目录”。数据库、材料副本和导出的 Word 都在这里。
卸载或升级应用不会主动删除这个目录。

安全说明
--------

经纬只监听这台电脑的回环地址，不是公网网站。核心功能不需要 API Key。
当前安装包尚未购买代码签名证书，Windows 可能显示“未知发布者”；请只从项目官方 GitHub Release 下载。
