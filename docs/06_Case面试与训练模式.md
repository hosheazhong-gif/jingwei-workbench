# Case 面试、在线训练与真实工作的关系

> 文档状态：研究附录。完整 Case Lab 不进入经纬 MVP；是否以独立模块实现，待核心咨询工作流验证后再决定。

## 1. 一句话回答

Case interview 是把真实咨询项目中的“问题解决核心”压缩成 20—60 分钟的模拟客户对话，用来观察候选人如何理解问题、构建分析、处理数字、形成判断和沟通建议。

它确实来自日常工作，但不是日常工作的完整复制。

McKinsey称其为典型客户场景，用来评估分析思维和解决复杂问题的方法；BCG称 case study interview 模拟真实客户问题；Bain称其为在协助下处理实际客户问题，观察合理假设、快速计算和共同推进；Deloitte也明确表示 case 代表真实客户 engagement，但重点仍是思考过程而非行业知识。[McKinsey Interviewing](https://www.mckinsey.com/careers/interviewing/en)、[BCG Case Preparation](https://careers.bcg.com/global/en/case-interview-preparation)、[Bain Interviewing](https://www.bain.com/careers/interview-preparation/experience-interview.aspx)、[Deloitte Practice Case](https://caseinterviewprep.deloitte.com/)

## 2. 为什么咨询公司用 Case

普通面试只能听你说“我善于分析”。Case 可以现场观察：

1. 你是否先确认客户目标；
2. 能否把模糊问题拆成可分析部分；
3. 是否提出有依据的初始假设；
4. 能否从图表和数字中找出真正含义；
5. 是否会做基本商业计算和估算；
6. 能否根据新证据调整方向；
7. 是否有客户和商业判断，而非只套框架；
8. 能否在信息不完整时给出有条件的建议；
9. 能否清楚、简洁地表达和与面试官协作。

所以 case 主要测试的是“顾问脑中的操作系统”，不是考你背了多少行业报告。

## 3. Case 与真实工作的重合程度

| 能力/任务 | Case 是否覆盖 | 真实工作中的情况 |
|---|---:|---|
| 澄清客户问题 | 高 | 项目启动、会议和内审反复发生 |
| 问题结构和假设 | 高 | 用于 scope、workplan 和分析优先级 |
| 商业数学 | 高 | 市场规模、利润、份额、ROI、break-even |
| 图表解读 | 高 | 从模型和数据中提炼 insight |
| 综合建议 | 高 | 每次模块更新和客户会议都需要 |
| 商业判断 | 中高 | 真实项目有更多行业和客户背景 |
| Desk research | 低 | Case 通常直接给材料，真实工作要自己找来源 |
| Excel/数据清洗 | 低 | 真实工作往往非常耗时 |
| PPT 制作 | 低 | Case 多为口头，真实工作反复写页和改页 |
| 访谈和工作坊 | 低至中 | Case 只有模拟对话，真实项目要设计和组织 |
| 团队协作 | 低 | 个别 group case 除外 |
| 客户政治与利益相关方 | 低 | 真实项目经常决定方案能否落地 |
| PMO、实施和变革 | 低 | 普通 case 很少覆盖长期推进 |
| 质量检查与版本迭代 | 低 | 真实项目的重要组成部分 |

准确说法是：

> Case 是真实咨询工作中“结构化解决问题和沟通”部分的高浓度切片，而不是完整工作体验。

## 4. “网上做 Case”可能指什么

### 4.1 在线练习案例

候选人在官网、咨询社团、培训平台或与伙伴练习公开案例。这只是备考，不计入招聘成绩。

官方练习入口包括：

- [McKinsey sample cases](https://www.mckinsey.com/careers/interviewing/en)：Beautify、Diconsa、Electro-Light、Talbot Trucks；
- [BCG case preparation](https://careers.bcg.com/global/en/case-interview-preparation)；
- [Bain practice cases](https://www.bain.com/careers/interview-preparation/experience-interview.aspx)：例如 Coffee Shop 和 FashionCo；
- [Deloitte interactive cases](https://caseinterviewprep.deloitte.com/)：同时有 Strategy 与 Business Technology Solution；
- [PwC Advisory case preparation](https://www.pwc.com/us/en/careers/why-pwc/what-we-do/advisory-case-study-prep.html)；
- [Strategy& business case prep](https://www.strategyand.pwc.com/m1/en/careers/business-case-prep.html)。

### 4.2 正式在线 Assessment / Game

这是招聘筛选，不一定是传统商业 case。

例如 McKinsey Solve 是游戏化 problem-solving assessment；可能测信息判断、系统关系、权衡和决策过程。它与真人 case 不同，也不等于日常工作软件。[McKinsey Solve](https://www.mckinsey.com/careers/mckinsey-digital-assessment)

其他公司和办公室可能使用数理、逻辑、情景判断、视频回答或在线商业案例，具体形式会变化，必须以当次招聘通知为准。

### 4.3 线上真人 Case Interview

传统 case 也可以通过视频会议进行。形式与线下面试接近：面试官给背景和数据，候选人口头分析。

### 4.4 Written / Slide-pack Case

候选人先阅读一组材料，再做建议或演示。Strategy& UK 官方说明同时存在：

- unstructured case：与面试官从开放问题开始；
- structured case：提供反映真实项目的 slide pack，约 10 分钟阅读后提出建议。

[Strategy& UK interview process](https://www.strategyand.pwc.com/uk/en/careers/professionals.html)

### 4.5 Group Case / Case Competition

几名候选人共同解决问题，额外观察协作、倾听、推动和影响力。学校咨询社团举办的 case competition 也属于这一类训练，但比赛形式可能比真实面试更强调最终展示。

## 5. 一场传统 Case 通常怎么进行

```text
1. 面试官给客户背景和问题
2. 候选人复述目标并提澄清问题
3. 候选人搭建问题结构和初始假设
4. 面试官分阶段提供图表、数字或新事实
5. 候选人计算、解释并更新假设
6. 面试官要求 brainstorm 或判断新情况
7. 候选人在 30—60 秒内总结建议、依据、风险和下一步
```

不同公司、办公室和面试官可能更主动引导，也可能让候选人自己推进。不要只背“某公司一定 interviewer-led / candidate-led”，因为具体形式会变化。

## 6. 一个与你相关的示例 Case

### 6.1 Prompt

> 客户是一家在三个城市运营 12 个商业项目的地产公司。过去两年招商周期变长，空置率上升。管理层考虑投入一套 AI 招商与运营平台，希望你判断是否值得投资，以及首先应做哪些功能。

### 6.2 你首先应澄清

- 管理层的核心目标是提高出租率、缩短招商周期，还是降低人力成本？
- 评估期限和投资回报要求是什么？
- 目前痛点集中在哪些城市、项目和业态？
- 客户已有的数据和系统是什么？
- 今天需要 go/no-go 判断，还是功能优先级？

### 6.3 一个问题结构

1. **业务价值**：招商和运营问题有多大，价值池在哪里？
2. **解决方案适配**：AI 可以改善哪些流程，效果证据是什么？
3. **实施可行性**：数据、技术、组织和合规是否支持？
4. **经济性与路径**：成本、收益、风险和试点顺序是什么？

### 6.4 面试官可能逐步给出的 Exhibit

- 12 个项目的空置率、租金和招商周期；
- 招商团队各流程的人时；
- 不同 AI 用例的投入和预估效果；
- 数据完整率和系统现状；
- 同行 benchmark；
- 三种供应商/自研方案。

### 6.5 可能要求的计算

- 每缩短一个月招商周期带来的租金价值；
- AI 线索评分和铺位匹配可覆盖的收入池；
- 三年收益、成本和 break-even；
- 在效果打折时的 downside case。

### 6.6 最后 Synthesis

候选人需要在几十秒内说明：

- 建议是否投资；
- 最重要的两三个依据；
- 先试点哪些用例；
- 最大风险和需要补的证据；
- 下一步是什么。

这个 case 是数字化转型项目的压缩版，但不会要求你真的清洗全部租赁数据、完成系统需求、做 30 页董事会材料或跑半年 PMO。

## 7. Case 常见题型不是固定框架

可以按客户决策认识常见题型：

| 题型 | 核心决策 | 常见分析 |
|---|---|---|
| Profitability | 利润为什么下降，怎么恢复 | 收入、价格、销量、组合、固定/变动成本 |
| Growth | 如何实现增长目标 | 核心业务、新客户、新产品、新地区、并购 |
| Market Entry | 是否进入、如何进入 | 市场、客户、竞争、能力、进入方式、经济性 |
| Pricing | 如何定价 | 价值、弹性、成本、竞争、细分、实施风险 |
| M&A / PE | 是否收购或投资 | 市场、标的竞争力、协同、财务、风险 |
| Operations | 如何提升效率和交付 | 流程、产能、瓶颈、利用率、供应链、质量 |
| Digital / Transformation | 投什么、如何转型 | 价值池、现状、用例、能力、case、roadmap |
| Public / Social | 如何实现公共目标 | 受益者、供需、政策、资源、实施和影响 |

这些只是问题家族，不应背成八套僵硬模板。面试评分更关注你是否针对当前问题形成合适结构。

## 8. 训练应拆成能力，而不是盲目刷题

### 第 1 层：单项 Drill

- 复述目标和澄清问题；
- 2 分钟结构；
- 心算、百分比、加权平均、盈亏平衡；
- 图表的“事实—含义—行动”；
- 30 秒 recommendation。

### 第 2 层：题型基础

理解盈利、增长、市场进入、定价、运营、尽调和数字化的基本商业逻辑。

### 第 3 层：Live Case

找 partner 或 AI 面试官进行 30—45 分钟完整练习。必须开口说，默读答案无法训练沟通和协作。

### 第 4 层：Written / Online

- 限时阅读 slide pack；
- 选关键数据；
- 形成 3—5 页建议；
- 单独熟悉正式 assessment 的说明和界面。

### 第 5 层：复盘

不要只记录“这题做错”。按能力记录：

- 是否理解错目标；
- 结构是否重叠或遗漏；
- 计算是否错误；
- 是否只读图没有 insight；
- 是否忽略客户和实施；
- synthesis 是否没有立场或依据。

## 9. 经纬 Case Lab 的设计

### 9.1 项目模式与 Case 模式共享什么

- 客户问题；
- 问题树和假设；
- 数据与 Exhibit；
- 分析逻辑；
- 选项和 recommendation；
- 行业/职能模板。

### 9.2 Case 模式必须隐藏什么

- 完整答案；
- 未经候选人提问的资料；
- 自动生成的问题结构；
- 实时计算和推荐；
- 参考 storyline。

### 9.3 训练结束后才提供

- 推荐问题结构；
- 计算检查；
- 漏掉的 insight；
- 面试表现评分；
- 更好的 synthesis 示例；
- 对应真实项目中被省略的工作。

### 9.4 评分维度

| 维度 | 观察点 |
|---|---|
| Problem definition | 是否理解目标、限制和成功标准 |
| Structure | 是否逻辑清楚、与问题相关、可执行 |
| Analysis | 数学、图表、假设和证据使用 |
| Business judgment | 是否考虑客户、竞争、能力和实施 |
| Adaptability | 新信息出现后是否更新判断 |
| Communication | 是否简洁、先结论、与面试官协作 |
| Synthesis | 是否有立场、依据、风险和下一步 |

## 10. 使用 AI 的诚信边界

可以用 AI：

- 解释商业概念；
- 生成练习题；
- 模拟面试官；
- 复盘结构、计算和表达；
- 提供训练计划。

不可以在禁止辅助的正式 assessment 或 case interview 中，让 AI 实时生成答案。McKinsey官方明确允许用 AI 准备，但禁止在面试/测评时使用 AI、网站、应用或预制笔记。[McKinsey assessment integrity](https://www.mckinsey.com/careers/assessment-integrity-expectations)

经纬 Case Lab 必须在界面和产品逻辑上明确这一边界。
