# docs 说明

这里是经纬的产品文档：第一性原理、PRD v0.1→v0.5、对象模型、可用性测试记录、
最小技术架构、现场缺陷台账、Multi-Agent 可行性方案和多类型工作台讨论稿。

## 关于 P-001

文档里反复出现的 **P-001 冷链园区**，是一个真实咨询项目的代号。这个项目被用作
产品的验证样本——因为只有拿真实的、不完整的材料走一遍，才能知道对象模型和
证据纪律撑不撑得住。

**客户身份、原始成果页、租户名单和经营数据不在本仓库内**，也不会进入本仓库。
文档中保留的是研究方法、判断链和产品结论，不是客户资料。
